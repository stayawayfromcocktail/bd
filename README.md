# ককটেল ও বাসে আগুন: সতর্কতা মানচিত্র

সংবাদমাধ্যমে প্রকাশিত ককটেল বিস্ফোরণ ও যানবাহনে আগুনের ঘটনার মানচিত্র, তালিকা ও সময়ের বিশ্লেষণ। পুরো সাইট একটি ফাইলে: `index.html`।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো সাইট (মানচিত্র, তালিকা, সময়, মন্তব্য) |
| `database.rules.json` | Firebase Realtime Database-এর নিয়ম; কনসোলের Rules ট্যাবে এটিই বসানো আছে |
| `.nojekyll` | GitHub Pages-কে ফাইলগুলো যেমন আছে তেমন পরিবেশন করতে বলে |

## GitHub Pages চালু করা

1. রিপোজিটরির **Settings → Pages**-এ যান।
2. **Source**: Deploy from a branch; **Branch**: `main`, ফোল্ডার `/ (root)`; Save চাপুন।
3. এক-দুই মিনিট পর ওই পাতাতেই সাইটের ঠিকানা দেখাবে।

## নতুন ঘটনা যোগ করা

`index.html`-এ `DATA-START` ও `DATA-END`-এর মাঝখানে প্রতি লাইনে একটি ঘটনা। শেষ লাইনের পরে কমা দিয়ে নতুন লাইন যোগ করুন:

```
{"d":"2026-11-11","s":"dhaka","ty":"bus","pl":"জায়গার নাম","en":"Place name","lat":23.783,"lon":90.344,"n":1,"u":"বাস","t":"21:30","note":"ছোট বিবরণ","src":"পত্রিকার নাম","url":"https://খবরের-লিংক"}
```

- `s`: ঢাকা মহানগর হলে `dhaka`, বাইরে হলে `dist`
- `ty`: যানবাহনে আগুন হলে `"bus"`; ককটেল হলে ঘরটি বাদ
- `t`: সময়, ২৪ ঘণ্টায় (`21:30`); ঠিক সময় না জানলে `"tb"` দিন: `late`, `dawn`, `morn`, `noon`, `eve`, `night` বা `dark`
- `inj`: আহতের সংখ্যা (থাকলে); `pol`: পুলিশের স্থাপনা হলে `1`
- ওপরের `"updated"` ঘরে তারিখ ও সময় বদলান

রাত ১২টার পরের ঘটনা পরের দিনের তারিখে লিখুন।

## মন্তব্য ও ভিজিট কাউন্ট

Firebase Realtime Database-এ জমা হয়; ঠিকানা `index.html`-এর `const CFG={db:"..."}` লাইনে। মন্তব্য মুছতে Firebase কনসোলের Data ট্যাবে মন্তব্যটির পাশের × চাপুন।
